# Skills

Personal Claude Code skills for this project, kept in the repo so they survive
and can be reinstalled — they are **not** auto-loaded from here.

## Install

```bash
cp -r docs/skills/genesis-ui ~/.claude/skills/
```

Skills placed in `~/.claude/skills/` are available across all your projects.
To make one load automatically for every collaborator instead, move it to
`.claude/skills/` in the repo.

| Skill | Purpose |
|---|---|
| `genesis-ui` | UI design and implementation — GBA-era pixel art, design-system enforcement, mockups, pixel asset authoring |
